# YardScale Digital

App studio and SaaS founder education site (Andrew Needham). Next.js 16, Tailwind v4, Supabase, Resend, Vercel.

The homepage is the funnel: video hero → problem → approach → offers → founder → proof → content → email capture → final CTA.
Pages: Home, Academy, Community, Coaching, Partnerships, About, Contact.

```bash
npm install
cp .env.example .env.local   # optional; the site runs without it
npm run dev
npm run lint && npm run typecheck && npm run build
```

Setup status, what is waiting on credentials, and where every editable value lives: **docs/SETUP.md**.
Working rules (never fabricate proof, placeholder states): **AGENTS.md**.
